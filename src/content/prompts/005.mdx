A new feature drop has finally arrived! Here are some of the highlights of what you can expect to find:

- A [standalone map converter](/convert) built right into the app
- Two new placement modes for obstacles
- Full support for color boost and basic transition events
- Improvements for filtering and grouping basic tracks
- New support for color scheme overrides
- Too many quality-of-life improvements and bugfixes 

This update is pretty jam-packed, so be sure to check out the [release notes](/docs/releases/0.5) if you want a breakdown on everything that's new and improved.
